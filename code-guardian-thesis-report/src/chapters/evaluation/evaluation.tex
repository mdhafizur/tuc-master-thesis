This chapter evaluates Code Guardian against the five requirements defined in Chapter~\ref{chap:analysis} and answers the research questions stated in Section~\ref{sec:intro-rqs}: detection accuracy (R1), consistency (R2), repair quality (R3), usability (R4), and privacy (R5). Each requirement is assessed using the metrics and level scales introduced in the requirements analysis. The evaluation uses a curated dataset of 101 test cases (71 vulnerable, 30 secure) covering major CWE categories, executed on local hardware with five Ollama models in both LLM-only and LLM+RAG configurations and three runs per sample. Three SAST baselines (Semgrep, CodeQL, ESLint) provide reference points. Headline figures for the best-performing configuration (\texttt{qwen3:8b+RAG}) are reported in the per-requirement sections and consolidated in Section~\ref{sec:eval-comparative}.

Sections~\ref{sec:eval-dataset}--\ref{sec:eval-setup} introduce the dataset, metrics, and experimental setup. Sections~\ref{sec:eval-r1}--\ref{sec:eval-r5} present results organized by requirement, each ending with a level mapping. Section~\ref{sec:eval-comparative} synthesizes the findings into a cross-requirement compliance overview and positions the measured outcomes against related work.
